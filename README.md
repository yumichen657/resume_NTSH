# ✏️ 怎麼修改網站（不用寫程式）

網站上的文字都放在 **`content`** 資料夾裡的文字檔，改文字檔就等於改網站。
全部都可以直接在 GitHub 網頁上完成，不用安裝任何東西。

```
content/
  網站設定.md              ← 首頁的大標題、副標題、頁尾
  頁面/
    競賽經驗.md            ← id: competition（網址 /competition）
    課外活動.md            ← id: activities
    幹部經驗.md            ← id: leadership
    社團經驗.md            ← id: club
    AI應用.md              ← id: ai
    多元選修課程.md        ← id: electives（目前沒顯示在首頁）
    多元選修_字典.md       ← 首頁的「字典」卡片
    多元選修_查詢股價.md   ← 首頁的「查詢股價」卡片
    鳴潮.md                ← 首頁的「鳴潮」卡片
```

**一個檔案＝一頁，網址＝檔案裡的 id。** 例如寫 `id: club`，網址就是 `/club`。檔名隨便取，只是方便你找。

## 1. 改某一頁的文字

1. 在 GitHub 打開 `content` → `頁面` → 點你要改的檔案（例如 `社團經驗.md`）
2. 點右上角的 **鉛筆圖示 ✏️**
3. 直接改字
4. 點右上角綠色的 **Commit changes…**，再按一次 **Commit changes**

每個檔案長這樣：

```
---
id: club
標題: 社團經驗
圖示: 🎵
首頁簡介: 透過社團活動探索興趣與培養責任感。
順序: 4
---
這裡展示我參加社團的活動與貢獻。
```

- **兩條 `---` 中間是設定**，每行是「名稱: 內容」，只改冒號後面的字
- **`---` 下面是這一頁的內容**，像寫筆記一樣直接打字

| 設定 | 作用 |
|---|---|
| id | 這一頁的網址，`id: club` 就是 `/club`。用英文、數字、`-`；**每一頁的 id 不能重複** |
| 標題 | 這一頁最上面的大字，也是首頁卡片的標題 |
| 圖示 | 標題前面的表情符號，可以不填 |
| 首頁簡介 | 首頁卡片上的一句話，也會顯示在這一頁的標題下面 |
| 順序 | 首頁卡片的排列順序，數字小的排前面 |
| 顯示在首頁 | 寫「否」就不會出現在首頁（網址還是打得開） |
| 連結 | 一般不用填。只有 ask、stock、mc 這種「功能頁」才用 |

## 2. 新增一頁

1. 打開 `content` → `頁面`，點右上角 **Add file → Create new file**
2. 檔名隨便取，例如 `志工服務.md`（**一定要以 `.md` 結尾**）
3. 貼上這段，改成你要的內容：

```
---
id: volunteer
標題: 志工服務
圖示: 🤝
首頁簡介: 參與社區服務，培養同理心與責任感。
順序: 5
---
這裡寫這一頁的內容。
```

4. **Commit changes**

網址就是 `/volunteer`（看 id），首頁會**自動**多一張卡片，不用改其他地方。
最快的做法：直接複製一個現有的頁面，改 id 和內容。

## 3. 刪除或隱藏一頁

- **暫時隱藏**：在設定加一行 `顯示在首頁: 否`
- **完全刪除**：打開那個檔案，點右上角的「…」→ **Delete file** → Commit changes

## 4. 加圖片

1. 打開 `static` → `images` 資料夾 → **Add file → Upload files**，把圖片拖進去，Commit changes
2. 在頁面內容裡寫：`![圖片說明](/static/images/你的圖片檔名.jpg)`

檔名要**一模一樣**，包含大小寫和副檔名（.jpg / .png）。

## 5. 改首頁的大標題、副標題、頁尾

打開 `content/網站設定.md`，改冒號後面的字。

## 寫內容的小抄

| 想要 | 這樣打 |
|---|---|
| 小標題 | `## 小標題`（# 後面有一個空格） |
| 粗體 | `**粗體**` |
| 清單 | 每行開頭打 `- `（減號＋空格） |
| 編號清單 | 每行開頭打 `1. `、`2. ` |
| 連結 | `[顯示的字](https://網址)` |
| 圖片 | `![說明](/static/images/檔名.jpg)` |
| 換段落 | 空一行 |

按 Enter 換行，網頁上也會換行。

## 改壞了怎麼辦？

- **格式打錯不會讓網站壞掉**，最多就是那一行沒有變成你想要的樣子
- 想復原：打開那個檔案 → 右上角 **History** → 找到改之前的版本 → 複製回來

# 給會寫程式的人看的

股價、字典、鳴潮這三頁是程式功能，不在 `content` 裡：

```
app.py                 網站入口：把下面這些功能接起來
routes/
  pages.py             首頁、鳴潮頁，以及 content 裡的所有內容頁
  content.py           讀取 content 資料夾的文字檔
  stock.py             查詢股價（證交所資料）
  dictionary.py        多語言字典（中文 → 韓文 / 拉丁文 / 日文）
data/dictionary.json   字典的單字
templates/             網頁樣板（index、page、ask、stock、mc）
static/css/            各頁樣式；static/images/ 圖片
```

本機執行：

```bash
pip install -r requirements.txt
python app.py
```

部署時的啟動指令：`gunicorn app:app`
